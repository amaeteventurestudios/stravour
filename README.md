# STRAVOUR

**House of Discipline — Private Phase**

---

## Project Overview

STRAVOUR is a private, early-stage premium liquor house operating in stealth. This website is not a public launch. It will only be shared directly with select institutional or strategic contacts.

---

## Live Entry Point

| Path | Description |
|------|-------------|
| `/index.html` | Single-page site — the sole entry point |

No additional routes. No subpages.

---

## Completed Features

- Single-page private presence built to approved copy (verbatim, unmodified)
- Locked color scheme: `#121212` background, `#E8E2D9` text, `#CFC4B6` accents
- Typography: EB Garamond (serif headings) + Inter (sans-serif body)
- No animations, no gradients, no metallic effects, no gloss
- `noindex, nofollow` meta tag — excluded from all search engine indexing
- Fully responsive layout (mobile and desktop)
- Max content width: 700px
- Generous whitespace and high-contrast typographic hierarchy
- Minimal hairline dividers in muted beige at low opacity
- Footer: wordmark repeat + "Private" status marker only
